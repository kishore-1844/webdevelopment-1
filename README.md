# Web Practical Assignment

This workspace contains practical exercises for HTML, CSS, JavaScript, MySQL, Node.js, and Supabase.

- Open [index.html](index.html) for the main navigation.
- Open [html/index.html](html/index.html) for HTML exercises.
- Open [css/index.html](css/index.html) for CSS and SaaS UI exercises.
- Open [javascript/index.html](javascript/index.html) for JavaScript and backend/database exercises.

Most HTML pages open directly in a browser. The MySQL, Node.js, and Supabase folders include setup notes where a local service, package installation, or project credentials are required.
