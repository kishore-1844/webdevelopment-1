# JavaScript, Database, and Backend Practicals

Open [index.html](index.html) for the complete folder navigation.

- `basic/`, `dom-manipulation/`, `events-advanced/`, `forms-advanced/`, `browser-features/`, `web-storage/`, and `mini-projects/` contain browser JavaScript exercises.
- `mysql/` contains the MySQL experiment workbook.
- `node-backend/` contains the Express REST/API scaffold. Run `npm install` and `npm start` there.
- `supabase/` contains the PostgreSQL schema, RLS policies, and Supabase client starter.
